# 数据库设计规范

## 1\.1 命名规范
| 对象 | 规范 | 示例 |
| :--- | :--- | :--- |
| 数据库名 | 小写 snake_case | agentic_commerce |
| 表名 | 前缀 ac_ + 小写 snake_case，单数形式 | ac_tenant、ac_task |
| 字段名 | 小写 snake_case，布尔字段用 is_ 前缀 | tenant_id、is_default |
| 主键约束 | pk_<表名> | pk_ac_tenant |
| 唯一约束 | uq_<表名>_<字段名> | uq_ac_sku_tenant_code |
| 索引 | idx_<表名>_<字段名> | idx_ac_task_tenant_status |
| 检查约束 | chk_<表名>_<字段名> | chk_ac_provider_type |

## 1\.2 主键规范

- 主键类型：`varchar(32)`

- 默认值：`replace(gen_random_uuid()::text, '-', '')`

- 关联字段：同样使用 `varchar(32)`

## 1\.3 审计字段规范

每张业务表必须包含以下 7 个审计字段：
| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| create_user_id | varchar(32) | 创建人 ID |
| create_user_name | varchar(100) | 创建人姓名 |
| update_user_id | varchar(32) | 更新人 ID |
| update_user_name | varchar(100) | 更新人姓名 |
| create_time | timestamptz | 创建时间，默认 now() |
| update_time | timestamptz | 更新时间，默认 now() |
| is_deleted | smallint | 逻辑删除，0=正常，1=已删除，默认 0 |

## 1\.4 外键策略

不创建数据库级外键约束，通过 `xxx_id` 字段逻辑关联，由应用层保证引用完整性，通过索引加速关联查询。

## 1\.5 索引策略
| 索引类型 | 使用场景 | 示例 |
| :--- | :--- | :--- |
| B-tree 单列索引 | 高频查询字段 | idx_ac_task_tenant_id |
| B-tree 复合索引 | 多条件组合查询，tenant_id 优先 | idx_ac_task_tenant_status |
| GIN 索引 | JSONB 字段查询 | idx_ac_knowledge_chunk_metadata |
| HNSW 索引 | 向量相似度检索 | idx_ac_knowledge_chunk_embedding |
| 部分索引 | 特定条件查询 | WHERE is_deleted = 0 |

## 1\.6 多租户隔离

- 所有业务表包含 `tenant_id varchar(32) NOT NULL`；

- 所有查询强制附加 `tenant_id` 过滤；

- 复合索引以 `tenant_id` 为首列；

- RAG 向量检索强制附加 `tenant_id` 过滤；

- 可选启用行级安全策略（RLS）作为额外防线。

## 1\.7 向量存储规范

- 向量维度：1024（千问 text\-embedding\-v4 / BGE\-large\-zh\-v1\.5）；

- 距离函数：余弦距离（`vector_cosine_ops`）；

- 索引类型：HNSW；

- HNSW 参数：`m=16, ef_construction=64`；

- 元数据：`metadata jsonb`。

## 2\.3 关系说明
| 关系 | 说明 | 类型 |
| :--- | :--- | :--- |
| 租户 → 用户 | 一个租户拥有多个用户 | 1:N |
| 租户 → 模型厂商 | 一个租户配置多个厂商 | 1:N |
| 租户 → 知识库文档 | 一个租户拥有多个知识库文档 | 1:N |
| 知识库文档 → 知识库分块 | 一个文档切分为多个向量分块 | 1:N |
| 租户 → 商品SKU | 一个租户拥有多个 SKU | 1:N |
| 租户 → 批次 | 一个租户创建多个批次 | 1:N |
| 批次 → 生成任务 | 一个批次包含多个生成任务 | 1:N |
| 商品SKU → 生成任务 | 一个 SKU 可多次生成 | 1:N |
| 生成任务 → 文案内容 | 一个任务产出多份文案 | 1:N |
| 生成任务 → 素材资产 | 一个任务产出多个素材 | 1:N |
| 生成任务 → 合规报告 | 一个任务产出一份合规报告 | 1:1 |
| 生成任务 → 节点执行记录 | 一个任务有多个节点执行记录 | 1:N |
| 商品SKU → 刊登记录 | 一个 SKU 可刊登到多个平台 | 1:N（二期） |
