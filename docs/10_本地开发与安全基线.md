# 本地开发与安全基线

更新：2026-11-05。对应分支：`feat/local-security-foundation`。

## 本机启动

在项目根目录使用 PowerShell 7：

```powershell
pwsh -NoProfile -File scripts/dev.ps1 -Action Start
```

需要已安装 Docker Desktop、uv、Node.js。首次运行会同步 Python 依赖、创建 `.env.local`、启动独立基础设施、升级数据库、创建开发管理员和素材桶；缺前端依赖时会执行 npm ci。随后在隐藏窗口中启动前后端，日志在 `logs/`。

- 前端：<http://127.0.0.1:5174>
- API 文档：<http://127.0.0.1:8002/docs>
- 存活检查：<http://127.0.0.1:8002/health>
- 依赖就绪检查：<http://127.0.0.1:8002/ready>
- PostgreSQL：127.0.0.1:5435；Redis：127.0.0.1:6381；MinIO API/控制台：127.0.0.1:9010/9011。

管理员邮箱和随机密码位于 `.env.local` 的 `BOOTSTRAP_ADMIN_EMAIL`、`BOOTSTRAP_ADMIN_PASSWORD`。登录页面不再预填公开演示凭据。

```powershell
pwsh -NoProfile -File scripts/dev.ps1 -Action Status
pwsh -NoProfile -File scripts/dev.ps1 -Action Stop
```

Stop 只停止有进程记录且创建时间/可执行文件匹配的本项目进程，以及本项目 Compose 的容器；保留数据卷。不会停止 CargoPilot。Setup 动作只准备环境，不启动前后端。

`.env.local` 优先于原有 `.env`；原文件和其中模型 Key 未被修改。新建本地配置默认 `ALLOW_MOCK_ASSETS=false`，实际生成会使用已有模型 Key，可能产生费用；本轮验证没有调用真实模型。需要离线演示时可在 dev/test 中显式设为 true，但模拟审核不会批准交付。

不要删除 `.env.local` 后直接重新生成并复用旧数据卷：新密码无法自动替换已有数据库/存储凭据。应保管配置备份。`.env*`、本地数据、进程记录、运行日志和助手历史均已排除提交，模板 `conf/.env.example` 例外。

## 数据库版本管理

新环境使用：

```powershell
uv run alembic upgrade head
uv run alembic check
```

初始版本 `7c4bb2de21ad` 包含当前业务表和 pgvector 扩展。`python -m app.scripts.init_db` 现在委托 Alembic。已有业务表的数据库需先核对结构，再决定迁移基线，不能盲目执行 stamp。开发 seed 仅在 dev/test 允许运行，示例知识分块暂不写入伪向量。

## 已实现的安全行为

- HTTP 接口无有效 Token 返回 401；Token 必须包含有效身份、租户、类型和有效期。
- 每次认证查询当前用户及租户状态，权限以数据库角色为准；模型配置页面/API 需要管理员。
- 批次 SKU、任务、素材登记和相关查询增加租户及软删除校验；文案编辑后旧审核失效。
- WebSocket 路径统一为 `/api/v1/ws/tasks/{task_id}`，第一条消息为 `{"type":"authenticate","token":"..."}`。服务端检查来源、身份和任务归属，只向该租户/任务发送事件；令牌不放进 URL。
- 审核缺字段、格式错误、模型失败、模拟结果、明确拒绝、禁词命中或缺真实媒体都不能批准交付。
- 关闭 Mock 后，文本、embedding、图片和视频调用都不能用模拟结果掩盖失败；正式环境始终禁止模拟回退。
- 非 dev/test 环境拒绝 DEBUG、Mock、关闭认证、默认/短 JWT 密钥、默认数据库/存储密码、通配来源/主机。
- `/health` 表示进程存活；`/ready` 检查数据库迁移表、Redis 和素材桶，依赖不可用时返回 503；设置页显示真实检测结果。
- 节点记录在持久化后再推送；后台异常将任务标为 failed，记录脱敏错误类型。
- 新建任务最多允许 2 次审核重试，批次最多 100 个 SKU，拒绝不支持的媒体类型和额外参数。
- 导出前检查任务、最新审核及真实产物；移除了虚假 ZIP 地址。真实归档下载尚未实现，页面会明确提示。

## 验证命令

```powershell
uv run --extra dev pytest tests/test_security.py -q
npm.cmd run build --prefix frontend
```

双租户集成测试必须使用独立、可丢弃且已迁移的 `_test` 数据库：

```powershell
$env:POSTGRES_DB = 'agentic_commerce_test'
$env:RUN_DB_TESTS = '1'
uv run alembic upgrade head
uv run --extra dev pytest -q
```

测试使用事务回滚，覆盖跨租户 SKU/批次/素材、角色伪装、审核导出阻断和编辑后审核失效。真实模型请求全部使用本地替身；集成测试未覆盖真实生成质量或付费接口。

本轮验证：46 项回归测试通过，前端 vue-tsc/Vite 构建通过，Alembic 结构一致性检查通过；在独立 `_test` 数据库完成降级到 base 后重新升级到 head。实际本机验证了启动/停止/重新启动、依赖就绪和真实数据库登录，CargoPilot 容器保持运行。没有进行浏览器端到端或真实模型效果验收。
