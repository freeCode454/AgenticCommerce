# 前端重做与本地验收

本轮范围为现有 15 个前端页面与共享组件。保留 Vue 3、TypeScript、Pinia、Vue Router、Axios；后端 REST、WebSocket、数据库及迁移文件未修改，不部署生产环境。

## 本地查看

访问 [本地工作空间](http://127.0.0.1:5174)。管理员邮箱与密码见根目录未提交的 `.env.local` 中 `BOOTSTRAP_ADMIN_EMAIL`、`BOOTSTRAP_ADMIN_PASSWORD`。

完整启动方式见 [本地开发与安全基线](10_本地开发与安全基线.md)。仅启动前端时，在 `frontend` 中执行 `npm ci`、`npm run dev`，后端仍需正常运行。

## 页面与组件

- 登录页采用深绿品牌简介与暖白表单，支持密码显示、记住邮箱、错误提示及登录后返回原页面。
- 240px 桌面侧栏；小于 1024px 使用导航抽屉。支持 Escape、焦点恢复及 Ctrl/Cmd+K 页面搜索。
- 首页、商品、任务、批次、素材、文案、审核、交付、刊登、知识库、模型、费用、设置和生成工作台均使用真实接口。
- 共享 `PageState`、`AppDialog`、`UiHost`、`StatusBadge`、`PaginationBar`、`MediaPreview`、`SkuPicker`、`TaskCreateDialog`；样式集中在 `src/styles`，业务类型集中在 `src/types`。
- `useCollection` 和 `useResource` 取消被替代的请求，并在离开页面时终止请求。筛选重置分页；错误、空数据与零值分别展示。
- 401 清理身份、保留站内返回路径；403 显示权限状态。模型服务同时限制菜单和直接路由。
- 工作台读取真实任务与节点记录，WebSocket 首帧发送任务鉴权；最多自动重连 5 次，间隔为 1、2、4、8、15 秒。连接中断时，每 5 秒刷新运行中任务，支持手动重连，切换任务或离开页面后清理连接及定时器。
- 模型输出通过 Vue 文本插值展示，不插入模型 HTML；媒体地址仅接受 HTTP/HTTPS，加载失败可重试。

## 当前能力边界

| 操作 | 当前行为 |
| --- | --- |
| 创建任务 / 批次 | 完整英文 Amazon 文案、图片、视频流程；任务重试上限可选 0–2，批次默认为 2；每批最多 100 件商品 |
| 独立图片、独立视频、其他平台生成 | 标注尚未开放，不提供与实际执行不符的选择 |
| AI 提取 / 生成 / 向量化 / 检索 / 模型测试 | 由用户主动触发，并说明可能产生费用；创建商品若有描述但没有规格，因后端自动提取行为增加费用确认 |
| 文案编辑 | 保存后提示重新审核；工作台标记旧审核失效。当前重新执行会生成完整内容，可能覆盖手工文案 |
| 模型配置 | 保存的是数据库记录；运行仍使用服务端环境配置，需管理员在服务端应用。运行测试验证当前环境配置，可能付费；不宣称数据库密钥已加密 |
| 费用 | 仅显示节点执行记录的实际汇总与预估费用，不展示后端固定比例分摊的模型分布 |
| 交付 | 查看接口返回的交付清单与原文件；ZIP 下载禁用并说明尚未开放 |
| 刊登 | 保留本地历史记录与平台介绍；实际发布禁用，本地记录不视为已上架 |

## 验证方式

2026-11-05 本地验收：TypeScript 检查与 Vite 构建通过；Playwright 26 项检查通过；现有后端 46 项回归检查通过。使用真实账号验证登录与全部列表、费用、设置的只读查询，未出现接口错误或浏览器脚本错误。任务产物、异常及断线场景使用拦截夹具验收，未调用真实生成模型。

在 `frontend` 中执行：

```powershell
npm ci
npm run typecheck
npm run build
npm run test:e2e
```

Playwright 默认复用 5174 端口的本地前端；没有启动时会临时启动 Vite。默认串行执行以降低 Windows 内存占用。Windows 优先使用已安装的 Chrome；其他环境先运行 `npx playwright install chromium`，或设置 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定浏览器文件。

浏览器检查包含登录成功与失败、记住邮箱、返回原页面、退出、401/403、管理员权限、页面搜索、弹窗及手机导航键盘操作、筛选分页与旧响应取消、表单防重复提交、文案保存、失效媒体、模型配置与运行状态区别、交付限制，以及工作台断线轮询、有限重连和离开时清理。

全部页面分别检查内容、空数据及接口失败状态，并在 1440、1024、390、360px 下检查长名称与页面级横向溢出。

`tests/fixtures.ts` 拦截所有业务 API，不向真实服务转发写入或模型请求。测试夹具仅属于测试目录，不进入业务页面。真实服务验收只执行登录与只读查询。现有后端回归检查在隔离测试数据库中执行：

```powershell
$env:POSTGRES_DB='agentic_commerce_test'
$env:RUN_DB_TESTS='1'
.venv\Scripts\python.exe -m pytest -q
```

本轮不会产生真实模型费用。真实模型生成、收费凭据切换和平台发布不属于本轮实调用验收，需要在后续后端能力完善后单独验证。
