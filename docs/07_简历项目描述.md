# 项目名称

AgenticCommerce — 自主智能体跨境电商内容生成中台

# 项目背景

跨境电商运营长期面临素材制作周期长（单品主图与短视频需 5–10 天）、多平台文案风格割裂且同质化、易触犯海外广告法违禁词导致封店等业务痛点。为提升内容生产效率并降低合规风险，开发了这套自动化内容生成平台。业务人员只需输入商品基础信息，系统即可在数分钟内自动完成需求分析、英文 Listing 文案撰写、商品图与短视频生成，以及合规质检全流程。

# 项目描述

该项目是一个企业级的多租户软件服务系统，引入了"多智能体"协作机制。系统内部包含七个独立的 Agent（编排调度、需求分析、创意策划、视觉设计、图片生成、视频生成、质量审核），通过 LangGraph 状态图进行任务流转与上下文传递。为确保生成内容的合规与质量，系统设计了"规划-执行-验证"的闭环：当质检不合格时，会自动将上一轮审核建议注入上下文，打回至"创意策划"节点重写文案；若重试超过上限（2 次），则终止流程并将任务标记为失败转入人工处理。最终生成的图文视频素材，需在可视化工作台经过业务人员的人工复核与在线编辑后方可交付。同时，系统沉淀了包含"品牌视觉规范、海外广告法违禁词表、细分品类爆款案例"的私有知识库，通过向量检索技术为智能体提供专业参考。

# 技术栈

Python 3.12、FastAPI、Pydantic v2、LangGraph、LangChain、SQLAlchemy 2.0（async）、PostgreSQL 16 + pgvector、Redis 7、MinIO、WebSocket、JWT、Docker Compose、Nginx、Vue 3 + TypeScript + Vite + Pinia；大模型侧接入通义千问（文本生成）、text-embedding-v4（1024 维向量）、通义万相（图像与视频生成）。

# 个人职责

- 多智能体工作流编排：基于 LangGraph StateGraph 搭建 7-Agent 有状态工作流，设计 AgentState 共享状态字典，利用 operator.add 归约器实现执行步骤的自动累加；编写条件路由（Conditional Edges），实现质量审核不通过时自动打回创意策划节点的 P-E-V 闭环重试机制，并通过 retry_count / max_retries 控制重试上限，避免死循环与 Token 浪费。

- RAG 知识库集成：独立负责品牌规范与合规文档的入库与检索服务，调用通义 text-embedding-v4 将文档转化为 1024 维向量写入 PostgreSQL（pgvector）；实现基于余弦距离的相似度检索与 top-k 截断，并在检索链路强制附加租户标识（tenant_id），保证多租户知识隔离不串库。

- 后端架构与 API 开发：遵循 Router-Service-Repository 三层架构，开发任务调度、文案管理、资产素材等核心业务 API（39 个 RESTful 接口 + 1 个 WebSocket 端点）；使用 FastAPI Depends 实现 JWT 鉴权与租户上下文注入；针对耗时的生图 / 生视频任务，使用 BackgroundTasks 实现异步处理，避免接口阻塞。

- 实时进度推送与可观测：基于 WebSocket 封装 ConnectionManager，实现 Agent 节点执行状态的实时广播与异常连接自动摘除；在节点执行过程中统一进行耗时、Token 消耗与费用的埋点记录，并持久化至 PostgreSQL，支撑前端工作台的数据统计与成本分析。

- 模型厂商适配与降级：封装 ProviderFactory 统一通义千问、通义万相的调用协议、超时与异常处理；实现无 API Key、接口非 200、网络异常三级 Mock 降级策略，保障接口欠费或宕机时业务流程仍可完整跑通。

- 多租户数据规范：完成 14 张业务表建模，统一 32 位 UUID 主键、禁用数据库物理外键、审计字段统一继承，全表强制 tenant_id 隔离，从数据访问入口杜绝越权。

# 项目成果

- 将传统需要 5–10 天的跨境物料制作周期缩短至分钟级，运营人员一次提交即可完成从需求分析到图文视频产出的全流程，极大提升了电商运营效率。

- 通过智能体质检与自动重试机制，将违禁词与极限词拦截在产出之前，质检不通过自动打回重写、超限转人工，大幅降低了人工审核成本与封店风险。

- 系统支撑从需求分析到视频生成的全链路异步调度，并具备完善的 Mock 降级策略（无 Key 或接口欠费、宕机时自动兜底），保障了业务的高可用性。

- 交付 7 个 Agent 节点、14 张业务表、39 个 REST 接口 + WebSocket 实时推送、15 个前端页面，后端约 4100 行、前端约 3900 行代码。
