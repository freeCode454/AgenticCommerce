# 浅蓝主题与账号导航优化

追加调整（2026-11-06）：按用户最新标注，移除侧栏工作空间卡片和底部账户栏；选中菜单仅保留浅蓝背景，移除深蓝左边线；顶部搜索与账号栏改为滚动时保持可见。账号信息和退出统一通过右上入口访问。

## 本轮改动

- 全部业务页和登录页统一为浅蓝底色、白色卡片及蓝色操作按钮。主色 `#2876CB`，页面底色 `#F4F8FD`，正文 `#20334F`，辅助文字 `#5C708B`；保留成功、警告和失败的语义颜色。
- 登录页改为浅蓝渐变品牌区，并统一耳机示意、SVG Logo、字标、favicon 和 512/1024 PNG。Logo 沿用原有图形，仅调整配色。
- 工作空间卡片支持多行名称，极长名称最多三行并可通过原生提示查看完整名称。侧栏保持 240px，收细滚动条并固定底部账户栏，避免被菜单挤出屏幕。
- 顶部搜索增加明确的输入框式边界，保留 Ctrl/Cmd+K 页面搜索；顶部高度收敛到 64px，搜索和账户控件统一对齐。
- 右上账户入口展示真实姓名和角色。展开后可查看邮箱和工作空间，前往已有设置页或退出；支持键盘操作、Escape 关闭、点击外部关闭及焦点恢复。
- 左下账户栏统一头像尺寸、文字层级与退出按钮位置。手机端保留精简的搜索和账户入口，导航继续使用抽屉。
- 首页流程卡片统一对齐，减少倾斜装饰，创作入口卡片改用浅蓝底，避免大片深色压迫感。

- 使用真实本机登录和只读数据检查桌面/手机工作台、登录页；浏览器自动化拦截业务写入及模型调用，没有触发真实生成。
