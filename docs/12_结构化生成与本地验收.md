# 结构化生成与本地验收

本轮修正文案与视觉节点中的固定商品模板，保持前端、业务 REST 接口、WebSocket 协议及数据库结构不变。当前范围仍是完整英文 Amazon 文案、三张图片及 5 秒商品视频。

## 已实现

- 文案节点将实际商品名称、类目、描述、规格、参考图地址、需求分析及上一轮审核反馈传入模型，要求返回 JSON。标题、五条卖点、描述、5–8 个关键词全部取自校验通过的模型字段，不再替换为露营椅文案或固定关键词。
- 视觉节点接收同一商品事实、文案及审核反馈，将模型返回的 `main_image`、`scene_image`、`detail_image`、`video_storyboard` 实际传给媒体节点。移除“有椅字就是椅子，否则耳机”的分支与统一营地背景。
- 视频方案要求与现有执行一致：5 秒、16:9；不再要求模型编排实际不会执行的 15 秒广告。
- 图片、视频节点调用厂商前校验完整提示词，缺失时终止，不使用通用或户外提示词补齐。
- 文案、视觉输出校验拒绝缺字段、空字符串、错误类型、超长文本、重复 JSON 字段、额外字段、混入解释的响应及模拟输出；支持纯 JSON 与单个完整 JSON 代码块。
- 模型可以返回 `{"error":"insufficient_product_data"}` 明确表示资料不足。缺少商品名称时，在调用模型前终止。
- 模型调用失败、结构不合法或文案保存失败，会记录对应文案/视觉节点的失败状态与可读原因；没有隐藏的自动补写、格式修复调用或成功回退。当前仍通过已有任务重新执行入口手动重试。
- 执行记录保存本次消息输入及校验后的结果，保留真实返回的 Tokens 和费用字段；失败提示不包含原始厂商响应或凭据。
- 审核节点收到商品原始规格、描述全文与关键词，提示模型核对未经证实的参数及品类错配；不再只审核描述的前 300 个字符。

## 校验与验收

2026-11-05：95 项后端检查全部通过，包括原有 46 项检查与新增 49 项检查。

新增检查覆盖：

- 杯子、耳机和帐篷分别保留各自模型结果，不发生代码层的品类替换。
- 结构、类型、长度、空字段、重复 JSON、模拟输出、资料不足及错误脱敏。
- 审核反馈与真实商品事实传递；完整描述与关键词进入审核上下文。
- 非法视觉方案阻断整个工作流，图片与视频客户端不被调用。
- 合法方案经实际工作流传给三种图片视角及 5 秒视频，并进入审核。
- 文案落库字段与模型结果一致；接口读取返回相同内容，租户与 SKU 归属保留。
- 非法结果不写入文案，数据库保存失败不报告成功，记录失败不会掩盖原始生成错误。

执行命令：

```powershell
$env:POSTGRES_DB='agentic_commerce_test'
$env:RUN_DB_TESTS='1'
.venv\Scripts\python.exe -m pytest -q
```

数据库测试使用既有隔离 `_test` 数据库和事务回滚。厂商调用均由替身返回固定测试结果，不向真实模型发请求，不写本地业务数据，不产生真实生成费用。

## 当前边界

结构校验保证字段完整和类型正确，不能证明模型输出的所有事实都正确。提示词约束与审核核对仍需真实商品的模型效果验收。当前只把参考图 URL 作为文本上下文传入，没有实现图片像素理解或真实视频画面审核。

后续已补齐模型配置生效与密钥加密、任务持久队列和视频恢复、轮次幂等、媒体归档、人工交付审核及 ZIP 下载。平台自动刊登与生产部署仍待完成。前端操作见[前端重做与本地验收](11_前端重做与本地验收.md)。

## 真实模型首单验收

当前项目默认使用华北2（北京）地域的百炼接口。API Key、模型和接口地域需一致，账号需具备相应模型的调用权限以及可用额度或余额。模型配置中的凭据来源可选择服务端凭据或工作空间加密密钥。[API Key 配置](https://help.aliyun.com/zh/model-studio/get-api-key/)、[地域与接入地址](https://help.aliyun.com/zh/model-studio/base-url)

| 用途 | 当前默认模型 |
| --- | --- |
| 分析、英文文案及机器审核 | `qwen-plus` |
| 知识库查询向量（存在可检索的知识库向量时） | `text-embedding-v4` |
| 三张 1024 × 1024 图片 | `qwen-image-3.0-pro` |
| 一条 5 秒商品视频 | `wan3.0-video` |

1. 管理员在模型服务页保存三类默认配置，核对凭据和模型名称。
2. 选一件资料完整的真实商品，确认名称、类目、描述和规格。
3. 新建单件任务，将审核失败时的自动重试设为 0，确认费用提示后发起。
4. 查看工作台节点与真实产物，核对内容事实、画面、耗时，以及厂商账单中的费用。
5. 管理员在审核标签批准或驳回本轮内容。批准且同轮素材归档完整后验证 ZIP。

排队中或执行中的任务可在工作台取消。该操作停止本地后续步骤，保留已有产物和已知远端任务 ID。已经发出的请求可能继续执行或计费。百炼的远端取消接口只支持仍为 PENDING 的异步任务。[异步任务管理](https://help.aliyun.com/zh/model-studio/manage-asynchronous-tasks)
