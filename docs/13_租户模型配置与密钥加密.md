# 租户模型配置与密钥加密

本轮让工作空间保存的默认模型配置用于实际调用，并加密保存 API Key。REST 路径、现有请求字段及数据库结构保持兼容；配置列表增加状态字段供前端展示。

## 生效规则

- 每种类型（语言、图片、视频）可以选择一条默认配置。设为默认时，在同一事务内取消该租户其他同类型默认项，并锁定租户行避免并发切换出现多个默认项。
- 新启动的工作流从数据库取得当前租户配置快照。已经启动的工作流保留原快照，不在生成过程中换模型或凭据。默认切换及模型保存不需要重启服务。
- 规格提取、创建商品时的自动提取、知识录入/检索、即时审核及后台完整生成均绑定当前租户；只使用语言模型的操作不会被无关图片配置阻塞。
- `credential_source=stored` 使用当前工作空间保存的密钥；`environment` 明确使用服务端默认凭据。清空工作空间密钥后，不自动改用环境密钥。
- 模型测试使用选中的已保存记录，包括备用记录，不会改为测试另一条默认记录。保存不调用模型；测试可能产生真实费用，需主动触发。
- 旧记录没有 `credential_source` 时显示“待保存应用”，继续沿用原先的服务端默认行为，避免意外启用旧模型 ID 或历史密钥。重新保存后按管理员选择应用。

## 可配置内容

三类适配器均支持模型 ID 与凭据来源；语言模型额外支持向量模型 ID。其他 JSON 字段会被拒绝，避免“保存了但执行未使用”的配置。

当前适配器仍为 DashScope 语言模型、Qwen Image 与 Wan 视频；历史类名 `KlingVideoClient` 为兼容保留，不表示新增了可灵接入。模型 ID 是否可用需以厂商权限与主动测试结果为准。当前流程的三张图、5 秒/16:9 视频及英文 Amazon 内容范围没有扩展。

知识向量记录所用模型，并只检索同模型的向量；未标记的历史向量按原实现 `text-embedding-v4` 处理。更换向量模型后需要重新录入或重建知识，保存模型配置不会自动付费重建索引。

## 密钥存储

API Key 使用 [cryptography 的 AES-GCM](https://cryptography.io/en/stable/hazmat/primitives/aead/#cryptography.hazmat.primitives.ciphers.aead.AESGCM) 加密，使用独立 32 字节主密钥、随机 12 字节 nonce，并把租户及记录 ID 作为认证关联数据。复制密文到其他租户/记录、密文被修改或使用错误主密钥时均无法解密，不会回退到其他凭据。

- 主密钥配置：`PROVIDER_ENCRYPTION_KEY`，base64 编码的 32 字节值，必须与 JWT `SECRET_KEY` 独立。
- 本地 `python -m app.scripts.setup_local` 为已有 `.env.local` 补充缺失主密钥，保留已有密钥、账号与数据库配置；新环境自动生成。主密钥不输出到命令行、不提交 Git。
- 生产环境必须显式提供有效主密钥。修改 JWT 密钥不会改变模型密钥的加密；更换加密主密钥需要保留旧主密钥并安排重新加密，不能直接覆盖或丢失。
- API Key 上限为 256 UTF-8 字节，密文可容纳于现有 512 字符列，无需数据库迁移。
- 列表不返回原密钥或密文，只返回固定遮罩与加密/旧格式/不可解密状态。编辑不填新密钥时保留原值，明确选择清空才删除。
- 参数校验错误不回显输入；SQL 日志隐藏参数，配置 JSON 禁止夹带密钥与自定义请求地址。

## 旧密钥迁移

管理员可针对一个租户先检查数量，再执行加密。该操作不调用模型、不启用旧配置，不输出密钥内容；失败时事务回滚，重复执行不会再次加密已有密文。

```powershell
.venv\Scripts\python.exe -m app.scripts.encrypt_provider_keys --tenant-id YOUR_TENANT_ID
.venv\Scripts\python.exe -m app.scripts.encrypt_provider_keys --tenant-id YOUR_TENANT_ID --apply
```

也可在模型服务页重新保存旧配置，旧格式密钥会在同次保存中加密。

## 验证范围

本地验收：141 项后端检查通过；6 项针对性浏览器检查通过（包含 1440、1024、390、360px 全页面内容布局及两项模型配置操作检查）。TypeScript 检查、Vite 构建与新增模块静态检查通过。

后端检查覆盖加解密、行绑定、篡改/错误主密钥、并发上下文隔离、默认切换、清空不回退、备用配置测试、角色与租户权限、接口不回显密钥、旧格式迁移及各业务调用入口。HTTP 替身还核对真实客户端请求中的模型 ID 与 Authorization。

前端检查覆盖模型配置保存、默认/备用选择、费用确认、密钥输入清理、不写入浏览器存储、修改配置后清除旧测试结果，以及四种宽度的全页面内容布局。TypeScript 与 Vite 构建通过。

所有模型请求使用替身；数据库写入仅发生在隔离测试库并事务回滚。真实服务验收限于登录、只读状态与配置查询。本轮不进行付费连通性验收或生产部署。
