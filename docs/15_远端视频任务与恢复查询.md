# 远端视频任务持久化与恢复查询

更新日期：2026-11-06。此次在本机开发环境实现，所有生成验收使用替身接口，没有调用真实付费模型，也未部署生产环境。

## 现在的行为

任务执行到视频节点时，先保存提交意图和加密凭据，随后只发出一次生成请求。收到厂商任务 ID 后，必须先把 ID 提交到数据库，再开始查询状态。等待中的视频任务释放本机执行名额，默认每 15 秒查询一次已有远端任务，不再占用一个协程持续等待数分钟。

新增 `ac_provider_job` 保存租户、所属完整执行、审核轮次、远端 ID、模型、接口地址、状态、查询失败次数和有效期。每个执行的同一审核轮次只允许存在一个视频请求。

| 中断位置 | 恢复行为 |
| --- | --- |
| 远端 ID 已落库，视频仍在排队或生成 | 继续 GET 查询同一个任务，不再 POST 生成 |
| 视频结果已落库，素材或节点记录尚未提交 | 复用已保存结果，并按远端任务去重素材及节点记录 |
| 视频节点检查点已完成，审核尚未开始 | 从审核节点继续，跳过文案、图片和视频生成 |
| 提交过程中断，没有可靠远端 ID | 标记“提交结果待核实”，不自动再提交；需核对厂商任务和费用 |
| 审核已开始，或文案/图片等其他付费节点中断 | 保留人工确认重跑的边界，不盲目重放这些请求 |
| 远端返回失败、取消、不存在或超过查询期限 | 显示终止原因，不自动创建新远端任务 |

审核恢复后仍遵守原任务的重试上限。审核未通过且尚有已授权的重试次数时，可能继续下一轮完整生成并产生费用。恢复本身不会重新生成已完成的文案、图片或当前视频。

数据库事务不能覆盖厂商的 HTTP 请求。如果厂商已经受理，但响应丢失或本机来不及保存 ID，仍然无法判断是否计费。系统保留这一不确定状态，不宣称厂商调用恰好一次。

## 配置与凭据

- 开始执行时，保存原始模型选择和加密凭据快照。视频任务还单独冻结提交时使用的模型、接口地址和查询凭据。管理员修改默认配置后，恢复查询不会跳到另一账户。
- 凭据继续使用独立 `PROVIDER_ENCRYPTION_KEY` 保护，并绑定租户、执行及模型类型或远端任务记录，不能把密文移到另一租户使用。API 不返回密文、完整凭据或内部检查点。
- `DASHSCOPE_VIDEO_API_BASE` 默认保留现有北京地域入口 `https://dashscope.aliyuncs.com/api/v1`。需要工作空间入口时，配置为 `https://你的工作空间ID.cn-beijing.maas.aliyuncs.com/api/v1`，或所选地域对应的阿里云入口。模型、Key 与入口须同地域。
- 地址只接受阿里云 HTTPS API 地址，不接受任意外部主机、URL 用户凭据、查询参数或片段。远端任务 ID 也经过格式验证，不能拼接任意查询路径。
- 新增 `VIDEO_POLL_SECONDS=15`。读取失败只重试查询，并逐步延长到最多 300 秒，不重新发起生成。重启后仍按数据库中保存的查询时间处理。

当前万相请求使用文档规定的 `input.media` 首帧格式，并传递实际选择的 `16:9` 比例，移除了旧代码中 `image_url` 和强制 `adaptive` 的请求方式。真实账户的接口可用性和生成质量仍需后续由用户主动付费验收。

## 结果有效期与费用

[阿里云万相 3.0 官方接口说明](https://help.aliyun.com/zh/model-studio/wan3-video-generation-api-reference)列出了异步提交、查询状态、任务 ID 和结果链接的有效期，并建议用合理间隔轮询。当前按提交意图时间起 24 小时采取保守的查询/结果期限。

此次保存返回的视频地址及到期时间，没有自动下载或转存文件。地址仍可能失效；接下来需要把素材转存到本项目对象存储，不能把这轮完成视为永久保存了视频。

移除视频固定计费数值。查询接口没有返回账单金额时，保存有限的数值用量，标记“费用待核对”；工作台和费用页说明这些视频费用未包含在合计中。旧费用数据保持原样，API 不再返回按固定比例编造的分模型费用分布。
